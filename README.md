# 📊 Sales Analytics Dashboard – Excel

Welcome to my **Sales Analytics Dashboard** project, created using **Microsoft Excel** to transform raw sales data into an interactive and visually engaging dashboard.

This project demonstrates how Excel can be used for **data cleaning, analysis, KPI tracking, PivotTables, charts, and interactive reporting**.

## 👩‍💻 Created By

**Hadiya Sherin**

---

## 📌 Project Overview

The **Sales Analytics Dashboard** provides a clear overview of sales performance using a dataset containing **500 sales records**.

The dashboard helps analyze:

* 💰 Total Revenue
* 📈 Total Profit
* 📦 Quantity Sold
* 🌍 Regional Performance
* 🛍️ Product Performance
* 📊 Category-wise Sales
* 📅 Sales by Year, Quarter, and Month
* 🔎 Interactive filtering and analysis

---
